# Protective Coating Capability

Protective coating is a stack decision, not a finish word. The coating only makes sense when the base finish, substrate, service boundary, and film route are already right.

The two common routes are AFP anti-fingerprint and PVD color. Both change how the surface behaves, but neither fixes a wrong substrate choice.

<p class="article-note"><em>Coating control begins with the face the buyer will see and clean, not with the coating name alone.</em></p>

## When a Coating Stack Makes Sense

Use protective coating only after the base grade, base finish, sample, and film route are clear. AFP and PVD change surface behavior, but neither one repairs a weak substrate or a wrong alloy choice.

| Open decision | Stack to test | Release check |
|---|---|---|
| Fingerprints and wiping are the issue? | AFP coating | tune coating feel, gloss, and sample match on the chosen base finish |
| Color or brand effect is required? | PVD finish | lock shade, substrate, bend trial, and handling rule |
| Coated panels still need fabrication? | coating-safe film | confirm adhesive and peel behavior before delivery |

## What Must Be Locked

- **Base grade:** the alloy still carries the corrosion boundary. Coating can improve touch or appearance, but it cannot rescue a wrong substrate.
- **Base finish:** AFP and PVD behave differently on 2B, BA, No.4, hairline, and mirror. The finish has to be named before coating.
- **Sample:** one agreed reference prevents color drift. Gloss, tone, and touch feel should be approved before production, not argued after delivery.
- **Film:** wrong tack can damage the stack. Film chemistry and peel behavior need to match coating, cutting, and delivery.

## AFP

AFP is a clear anti-fingerprint layer applied over a finished surface.

| AFP control point | Typical value |
|---|---|
| Film thickness | 10-20 um |
| Best base finishes | No.4, Hairline, BA, mirror |
| Common bases | 304 / 304L, 316 / 316L, 430 |
| Main control | sample match and lot repeatability |
| Main risk | coating on the wrong film or wrong bend plan |

AFP is useful when the job is touched often and wiped often. It is not a substitute for a better alloy in humid or chloride service.

## PVD Color

PVD adds decorative color. It changes appearance first and service behavior only within a narrow indoor window.

Use color as a controlled sample decision, not a catalog promise:

- Gold and rose gold work best for hospitality, retail, and interior panels where tone is approved by sample.
- Black is useful for appliances and architecture, but scratch visibility has to be discussed early.
- Bronze belongs on signage and feature panels only after the substrate and service boundary are clear.

If the face will be handled often, AFP over PVD can help. If the face will be outdoors or chloride-heavy, the alloy choice still comes first.

## Layering Order

Typical controlled stack:

1. Base finish on the correct substrate.
2. PVD color if the brief needs color.
3. AFP if touch visibility must be reduced.
4. Film chosen for the real downstream process.

## Where the Stack Works

- Interior feature panels and appliance fronts
- Elevator details and hospitality accents
- Decorative trim where print control matters
- Sample-driven color work with tight visual acceptance

## Where It Does Not

- Coastal exterior service
- Heavy washdown and abrasive cleaning
- Any job where coating is being used to rescue the wrong base alloy

## Release Check

1. Confirm the base finish before coating.
2. Confirm the sample before production.
3. Confirm the film before shipping.
4. Confirm the service boundary before the coating is sold as protection.

Protective coating should answer one question: does the stack improve the release route without hiding a weak substrate decision? If the answer is no, the coating is not the fix.
