# Stainless Steel Slitting & Edging

Slitting and edging turn master coil into a controlled strip route. Width tolerance and edge condition decide whether the downstream process runs smoothly or starts rejecting parts.

<p class="article-note"><em>The strip is judged by what the next line can run: width, edge, rewind, and surface protection together.</em></p>

## When Slitting Needs a Controlled Route

Use slitting and edging when master coil must become controlled strip for tube mills, roll formers, stampers, or narrow-stock programs. Width tolerance and edge condition decide whether the next line runs cleanly.

| Open decision | Route to set | Release check |
|---|---|---|
| Tube mill or roll forming feed? | slit coil program | control width, burr, rewind, and coil build |
| Edge touches people or forms tightly? | deburred or rounded edge | set edge condition before packing |
| Finish-sensitive strip? | film and edge review | decide whether protection happens before or after slitting |

## What Has to Be Controlled

- **Width:** the next machine reads the slit width first. Tube mills, roll-formers, and stamping dies depend on the width stack being agreed before setup.
- **Edge:** burr, radius, and edge type decide the release. Mill, sheared, deburred, and rounded edges each behave differently in forming and handling.
- **Film:** protection timing changes the rewind plan. Pre-slit and post-slit film do not protect the same risks, especially on visible strip.
- **Rewind:** a clean edge still needs a stable coil. Rewind and packing protect edge condition after the strip leaves the slitter.

## Working Envelope

| Parameter | Typical range |
|---|---|
| Slit width | 10-1,500 mm |
| Thickness | 0.3-6.0 mm |
| Master coil ID | 508 mm / 610 mm |
| Master coil OD | up to 1,800 mm |
| Slit coil OD | up to 1,200 mm |
| Standard width control | set by thickness, width, edge route, and PO class |
| Precision width target | +/- 0.1 mm after route review |
| Burr height after deburr | <= 0.05 mm |

Treat +/- 0.1 mm as a precision target, not a blanket promise across every thickness and width. Strip below 10 mm is possible only by special review because edge control gets tighter as width narrows.

## Edge Conditions

- **Mill edge:** use only where the edge is hidden. It is the least controlled edge and should not carry hand-contact or tight forming risk.
- **Sheared:** good for general fabrication, but burr still needs checking if the strip feeds a tighter downstream process.
- **Deburred:** the safer default for stamping, roll forming, or handling where burr risk becomes visible.
- **Rounded:** reserve for hand-contact parts. It needs a separate conditioning pass and should be named before packing.

## What Slitting Changes

Slitting does not change the alloy, but it does change the edge. That matters in wet or chloride-bearing service where the slit edge becomes the first point to inspect.

The practical issue is not strength loss. It is whether the edge is clean enough for the next process and whether the coil stays stable after rewind.

## Release Controls

- Confirm the target width stack before setup.
- Confirm whether the edge is sheared, deburred, or rounded.
- Confirm whether film goes on before or after slitting.
- Confirm the packing method for the wound coil.

## Application Logic

- Tube mill feed: lock width and burr because width drives tube OD.
- Roll forming: lock width and edge condition because profile repeatability depends on both.
- Stamping strip: lock width and flat rewind because die clearance is unforgiving.
- Visible trim: lock edge and surface protection because the edge will be seen.

Slitting should be ordered as controlled feedstock rather than narrower coil. When width, edge, film, rewind, and packing are written clearly, the strip behaves the way the downstream line expects.
