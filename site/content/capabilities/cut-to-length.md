# Stainless Steel Cut-to-Length

Cut-to-length is the point where coil becomes a release-ready panel or blank. The route only works when flatness, size, edge condition, and film are decided together.

<p class="article-note"><em>Flatness and face handling should be visible in the route, not left to receiving inspection.</em></p>

## When CTL Is the Right Route

Use cut-to-length when coil must become a release-ready panel, blank, or sheet stack before shipment. The work is cutting length and locking flatness, burr, squareness, film, and packing as one route.

| Open decision | Route to set | Release check |
|---|---|---|
| Laser or press-brake work follows? | leveled cut sheet | set flatness, film, and cut-size tolerance together |
| Visible face will be inspected? | finish-protected CTL | control grain, film, stacking, and packing marks |
| Precision length matters? | precision CTL | confirm tolerance tier before coil is released |

## What Has to Be Locked

- **Length:** choose the tolerance tier before release. Standard and precision length are different routes, not a last-minute inspection note.
- **Flatness:** remove coil memory before the sheet is judged. Leveling changes how panels behave in laser cutting, bending, and visible installation.
- **Face handling:** keep film, stacking, and packing together. Clean faces still mark each other if separation and peel-off timing are left vague.
- **Edge:** name burr, squareness, and heat-mark expectations. The cut route should say what the receiving side is allowed to accept.

## Working Envelope

| Parameter | Typical range |
|---|---|
| Length | 500-6,000 mm |
| Thickness on shears | 0.3-6 mm |
| Thickness on laser | up to 50 mm |
| Width | up to 1,524 mm |
| Standard length tolerance | +/- 1.0 mm |
| Precision length tolerance | +/- 0.5 mm |
| Flatness after leveling | up to 1 mm/m on precision orders |

## Release Controls

- Tension leveling reduces coil memory and crossbow before the sheet is judged.
- Deburr or burr-limit language keeps touch safety and downstream forming out of guesswork.
- Film before cut protects the face from the first separation point onward.
- Export packing prevents face-to-face damage and corner marking after the panels leave the line.

## Practical Rule

Cut-to-length should be ordered as a finished blank, not as "shorter coil." If the receiving side needs flat, clean, and ready-to-use panels, the release route must say so up front.

The sheet is only release-ready when size, flatness, edge condition, film, and packing are all in the same decision.
