# Jinling 内容实质提升建议与证据材料清单

来源：`jinling-content-substance-score-report.md`

当前内容实质分：84.48 / 100。不是差，而是“已经有行业内容基础，但证据、素材、买家动作和 Jinling 特色还可以更稳”。下一步不要全站重写，优先补证据和调整低分页面族。

## 一、优先提升方向

### P1：Insights / 市场洞察

问题：分数最低，主要像行情摘录，Jinling 的判断方法、买家动作、风险边界不够稳定。

建议每篇市场洞察固定补三块，但文字要克制：

- `Buyer takeaway`：这周买家应该看什么，不应该误读什么。
- `What could change this view`：哪些库存、期货、出口证、原料或需求信号会推翻当前判断。
- `Source basis`：数据来自哪里，Jinling 如何解读。不要写成 guaranteed forecast。

需要补充材料：

- Wuxi / Foshan / mill offer / inventory 的原始数据截图或表格。
- 每篇周报对应的日期、数据来源、是否为公开来源。
- Kary 或团队对行情判断的简短口述，比如“我们不会把一周库存下降直接理解成需求恢复”。
- 出口证、关税、反倾销等政策信息的来源链接或截图。

注意：所有 `guaranteed / always` 类措辞要改成条件语言，比如 `may`, `usually`, `can`, `when the route is confirmed`。

### P2：应用详情页

问题：Automotive、Medical、Oil & Gas 等应用页有行业通识，但 Jinling 自己能控制什么还不够清楚。

建议每个应用页补一个轻量模块：

- `What Jinling can actually control here`
- `What the buyer should lock before quote`
- `Where this application should not be simplified`

需要补充材料：

- 行业实物图：汽车排气管、医药/食品卫生管、化工管道、水处理、建筑/电梯板材等。
- 对应材料细节图：焊缝、管端、内壁、膜、表面、包装、标签、MTC。
- 行业释放记录：例如 A270、NACE、PMI、hydro test、Ra 检测、清洗/钝化要求。可打码。
- 真实项目的“非客户敏感”描述：国家、产品形态、等级、表面、关键风险，不要写客户名也可以。

如果没有真实项目照片，可以先用样板、检测、包装、半成品细节图，比 AI 场景图更可信。

### P3：Datasheet / Grade 详情

问题：有参数，但“如何使用这份资料”还不够。买家读完知道数值，却不一定知道怎么下单、怎么避免误用。

建议每个 datasheet / grade 页补三类短说明：

- `Use this datasheet for...`：适合哪些采购/技术判断。
- `Do not use it as...`：不要把 datasheet 当成最终适用性保证。
- `Confirm on the MTC / PO`：哪些值必须在 MTC、标准、热号或订单里确认。

需要补充材料：

- 打码 MTC 样本：304、316L、430、2205、201 各一份即可。
- 标准依据：ASTM A240 / A480、EN 10088、JIS、UNS 等页面引用来源或内部标准摘录。
- 2205 PREN 计算示例：用真实热号化学成分说明“about 35 / heat chemistry confirms exact value”。
- 等级误用案例：比如 304 用在沿海、430 用在潮湿室外、201 用在高湿环境的边界说明。

### P4：知识库低分页

问题：不是文章不好，而是低分页通常有两个问题：内链偏密、Jinling 观点和证据图不足。

优先处理：

- `/knowledge-base/reading-a-wuxi-weekly-stainless-price-report`
- `/knowledge-base/the-one-step-most-export-sheet-packaging-skips`
- 报告里其他 80 分以下或刚过 80 分的文章

建议：

- 每篇只保留 3-5 个关键内链，其他移到底部 `Related reading`。
- 首段补一个 40-60 词的直接答案块，适合 Google snippet / AI 摘取。
- 增加一张证据图或流程图，不要为了装饰加图。

需要补充材料：

- 采购报告截图、库存/行情示例、打码订单路线图。
- 包装错误与正确包装对比图。
- 收货检查清单、投诉处理记录、照片证据。

### P5：Hub 页面

问题：Products Hub、Capabilities Hub、Knowledge Hub 分数低于核心详情页，说明它们还像目录，不够像“决策入口”。

建议：

- 不增加很多卡片。
- 每个 hub 顶部加一句“这个页面帮你决定什么”。
- 把入口从“栏目名”改成“问题入口”，例如 `Choose the product form first`、`Start from the release risk`。

需要补充材料：

- 不需要大量新图。优先用已有真实图做 1-2 张“路线证据图”。
- 可以补一张总路线图：raw material → finish → processing → packing → documents。

## 二、硬数字与强 claim 的证据包

这些数字可以保留，但必须有边界。没有证据时，宁愿降级表达，也不要硬撑。

### No.8 / 8K Mirror

当前可讲特色：慢速抛光、24 oscillating heads、430 mirror capable、raking-light release。

需要补充：

- No.8 抛光线照片/视频，最好能看到多组研磨头。
- 光泽度仪 GU 测量照片或记录。
- 粗糙度仪 Ra 测量照片或记录。
- raking-light inspection 现场照片。
- 430 mirror 样板图，最好含 304 / 430 / 201 对比。
- 低硫基材 MTC 打码样本，证明 S 控制逻辑。
- 镜面保护膜、包装、出货前检查图。

如果没有完整检测记录，页面中不要写得像每一批都稳定达到某个数值；改成 `target / typical / confirmed by agreed inspection method`。

### AFP 防指纹

需要补充：

- AFP 涂层线或涂布过程照片。
- 涂层厚度检测记录，10-20 µm 需要有测量依据。
- 指纹擦拭前后对比图。
- 清洁剂/耐污/耐温测试记录或内部测试说明。
- AFP 与激光膜、折弯、清洁习惯的兼容性说明。

如果 AFP 配方是内部机密，不需要公开配方，但要公开测试方法和验收方式。

### Super Finish 6×

这是最高风险 claim。可以成为 Jinling 特色，但必须有测试语境。

需要补充：

- 6× 的测试方法：盐雾、浸泡、电化学、点蚀测试，具体是哪一种。
- 对照组：原材是什么标准、什么等级、什么表面。
- 样本数量、测试时间、环境、判定标准。
- 第三方报告优先；如果是内部测试，也要写清 `internal comparative test under defined conditions`。
- 哪些环境不适用：强氯化物、缝隙腐蚀、焊后热影响区、错误等级选择。

如果暂时没有报告，建议把 `6× corrosion resistance` 降级为 `tested as a corrosion-margin upgrade in defined internal comparisons`，不要作为泛化承诺。

### Sanitary Tube 600 grit / 24 bar

需要补充：

- ASTM A270 对应文件或供货标准。
- 内壁 600 grit 抛光照片，最好有内窥镜或切样照片。
- Ra 检测记录，因为 grit 不等于 Ra。
- 24 bar 水下气密测试视频/照片，带压力表。
- 每批/每支测试记录的打码样本。
- 氮气退火、焊缝、管端保护图。

措辞建议：`up to 600 grit when specified`、`hydrostatic / underwater test route confirmed by order scope`。如果确实每支都测，也要说明适用产品线，不要扩展到所有 tube / pipe。

### Industrial Pipe 100% hydro / NDT

需要补充：

- Hydro test 记录。
- Eddy current / UT / wall thickness check 的检测记录。
- 哪些标准或订单要求下是 100%，哪些是抽检或按项目指定。
- 管材端口保护、喷码、标签、捆扎、装柜图。

不要把某一类 pipe 的检测承诺扩展到所有工业管。

### Slitting / Cut-to-Length / Processing

需要补充：

- Slit width 测量照片，含卡尺/卷尺/检测台。
- Burr / edge condition 近景。
- Coil ID / OD / rewind weight 照片。
- Cut-to-length 的对角线、平整度、膜保护、托盘包装照片。
- 不同厚度/宽度下 tolerance 的适用边界。

## 三、真实照片优先级

最值得先整理的照片，不是大而全的工厂宣传图，而是能证明“Jinling 会把订单做稳”的细节图。

### 第一优先级

- No.8 mirror 样板、检测、包装。
- AFP 指纹/清洁测试。
- 管端护棉、去蜡、去毛刺。
- 24 bar 测试、600 grit 内壁。
- MTC、COO、packing list、inspection report 打码样本。
- 出口包装、托盘、木箱、集装箱装柜。

### 第二优先级

- Slitting / CTL / laser / bending / welding 过程图。
- 不同产品形态：coil、sheet、tube、pipe、bar 的真实库存图。
- 各应用行业的材料细节图，而不只是场景图。

### 第三优先级

- 团队、Kary、质检人员、仓库、办公室。
- 客户样板或展会图，前提是授权清楚。
- 高质量定制图，用于缺少真实照片的知识库解释图。

## 四、外部证据与 GEO / AI 摘取

如果想让 AI 搜索更愿意摘取，不能只靠自己说。

建议补充：

- 标准来源：ASTM / EN / JIS / NACE / ISO 的引用说明。
- 行业协会或公共资料链接：例如 ISSF、Nickel Institute、Outokumpu 技术手册、IMOA 等。
- 每篇核心知识库文章至少 1-3 个可引用来源，不要堆太多。
- 页面中保留短答案块：40-60 词，能独立回答一个问题。
- 作者/审核者信息：`Jinling Steel Editorial Team` + `Materials Engineering Team` 已有，核心页可加 `Reviewed for technical release`。

## 五、不要补的东西

- 不要随便加 ISO / SGS / REACH 徽章，除非有真实证书和展示授权。
- EN 10204 3.1 是文件类型，不是公司认证，不要做成 badge。
- 不要为了 SEO 加很多内链，低分项已经提示“内链克制”是短板。
- 不要把 AI 生成行业大场景图当作核心证据。工业买家更信细节图。
- 不要把“最快、最大、最强”作为品牌语言。Jinling 更适合“细节、稳、释放、边界、长期关系”。

## 六、建议执行顺序

1. 先整理硬 claim 证据包：No.8、AFP、Super Finish、sanitary tube、industrial pipe。
2. 再补真实照片：优先替换 generated 信号页面和低分应用页。
3. 然后改 Insights：每篇加 buyer takeaway、source basis、not forecast 边界。
4. 再改应用页：Automotive、Medical、Oil & Gas 先做。
5. 最后整理 datasheet / grade：补使用语境，不大幅加文字。

如果材料暂时不齐，先做“降级表达”也能提升专业可信度。真正高级的内容不是把话说满，而是知道哪里该停。
