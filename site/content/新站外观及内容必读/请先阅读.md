# 金凌网站交付包说明

这是 `jinling_web_20260428` 交付包，用于分享当前整改后的 Jinling Steel 网站、运行依赖说明、照片素材清单、内容实质建议，以及两份评分报告。

## 推荐阅读顺序

1. `运行与依赖说明.md`：技术人员按这里启动网站。
2. `网站美观评分报告.md`：查看全站视觉评分和主要美观问题。
3. `内容实质评分报告.md`：查看内容专业性、买家价值、SEO/GEO、语言风格评分。
4. `照片素材整理清单.md`：整理下一批真实照片时使用。
5. `内容实质提升建议.md`：整理检测报告、MTC、工艺证据、应用案例时使用。

## 当前两项评分

- 网站美观评分：84.19 / 100
- 内容实质评分：84.48 / 100

这两个分数都不是“不能用”，而是说明网站已经进入可分享、可继续打磨的阶段。下一步最值得提升的是：真实工业证据、Insights 内容边界、应用页的 Jinling 特色、datasheet / grade 的使用语境。

## 文件夹结构

- `网站源码/`：Next.js 网站源码，不含 `node_modules` 和 `.next`。
- `评分原始数据/`：两套评分的 JSON 摘要和页面族数据。
- `照片素材整理清单.md`：每类页面需要补哪些照片。
- `内容实质提升建议.md`：需要补哪些证据、检测材料、报告和边界说明。
- `网站美观评分报告.md`：website-visual-scorer 全站视觉评分。
- `内容实质评分报告.md`：Jinling Content Substance Score 全站内容实质评分。

## 一个重要说明

交付说明类 Markdown 文件已使用中文文件名。`网站源码/content/` 里的 Markdown 文件名仍保留英文，这是网站 URL slug 和路由的一部分，不能随意改成中文，否则网页路径会失效。
