# 运行与依赖说明

## 环境要求

- Node.js：建议 20 或更高版本。
- 包管理器：npm。
- 系统：macOS、Windows、Linux 均可。

## 启动步骤

进入网站源码目录：

```bash
cd 网站源码
```

安装依赖：

```bash
npm ci
```

本地启动：

```bash
npm run dev -- --webpack -p 3011
```

浏览器打开：

```text
http://127.0.0.1:3011/
```

## 构建检查

如果要检查是否能正式构建：

```bash
npm run build
```

如果只检查代码规则：

```bash
npm run lint
```

## 本包没有包含什么

为了让文件包更轻、更容易分享，本包没有包含：

- `node_modules/`
- `.next/`
- `.git/`
- 本机缓存文件

这些都可以通过 `npm ci` 和 `npm run dev` 在接收方电脑上重新生成。

## 依赖文件

必要依赖已经通过下面两个文件保留在 `网站源码/` 中：

- `package.json`
- `package-lock.json`

接收方不要手动复制旧电脑上的 `node_modules`，直接运行 `npm ci` 更干净。
