# 8K Mirror Finish Datasheet

8K mirror is the high-reflectivity stainless finish. It is released by reflection quality, not by the word mirror alone.

Jinling check: use this when reflection is the acceptance point. Verify substrate, Ra or gloss target, film, packing, and the viewing condition before production.

## Use This When

Use 8K mirror for indoor decorative panels, elevator interiors, and lobby features when reflection is part of the design language.

Keep a visible-face sample if several lots will meet on site. For coastal, wet, or cleaning-heavy work, solve substrate first; mirror polish does not add corrosion reserve. If haze, pinholes, or scratches may be disputed, lock the viewing condition before bulk release.

## Release Notes

- Target level: standard 8K is usually released around Ra <= 0.05 um; tighter lots need explicit approval.
- Directionality: no visible directional line should remain in the reflection.
- Protection: film and packing are part of the finish, not an accessory.
- Sample: use a visible-face sample when gloss, haze, or lot consistency matters.

## Verify Before PO

1. Name substrate and mirror target together: 304 mirror, 316L mirror, or 430 mirror.
2. State whether the face is final-use or a base for AFP or later processing.
3. Confirm film type, viewing condition, and acceptance sample.
4. If the project is coastal or wet, solve the substrate before arguing about gloss.
