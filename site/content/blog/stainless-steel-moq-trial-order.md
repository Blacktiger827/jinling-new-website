# What Makes a Stainless Trial Order Worth Running?

There is no honest universal MOQ for stainless steel. A stock 304 sheet order, a polished mirror order, a slit coil order, and a sanitary tube order do not have the same minimum.

A good trial order is not the smallest quantity a supplier will tolerate. It is the smallest order that tests the route you will actually buy later.

## What MOQ Really Depends On

| Route | Why the minimum changes |
|---|---|
| stock sheet, coil, bar, or tube | supplier can pull from existing inventory |
| slit or cut-to-length material | line setup and packing must be justified |
| polished, mirror, AFP, or PVD finish | sample approval, film, and finish release add cost |
| non-stock grade or size | mill run or sourcing minimum controls the order |
| mixed container | loading plan and document pack become the real constraint |

When a supplier says "no MOQ", it usually means there is no single tonnage floor for standard stock. It does not mean every custom route can be bought cheaply in tiny lots.

## What a Trial Should Test

A serious trial order should test:

- whether the supplier understands the specification
- whether the finish matches the approved sample
- whether MTC and origin documents arrive correctly
- whether packing survives export handling
- whether communication is calm when something small changes

If the trial skips the finish, document, and packing requirements that will matter in volume, it only proves that a small quantity can be shipped. That is not enough.

## Do Not Test a Different Order

A trial should not quietly change the route to make the minimum easier. If the volume order will use AFP film, export crate packing, final MTC review, and mixed-container labels, the trial should include those steps or clearly state that it is only a surface sample.

The danger is false confidence. A cheap trial pulled from easy stock can make both sides feel ready, then the real order fails at the first custom finish, document, or packing requirement.

## When a Small Order Is a Bad Order

Small orders become bad when they force the supplier to use leftover stock, change the process route, or ship with a document pack different from the future volume route.

For example, a 50 kg sample of polished sheet does not prove a 10 tonne mirror order will match lot-to-lot. A few pieces of sanitary tube do not prove the full inspection path unless the same weld, polish, test, and document route is used.

## PO Wording

Write the trial as a route test:

> "Trial order to follow future volume route: grade, finish, processing, MTC, packing, labels, loading photos, and document pack to match expected repeat order."

If the goal is only visual approval, say that too. A sample trial and a supply-chain trial are different animals.
