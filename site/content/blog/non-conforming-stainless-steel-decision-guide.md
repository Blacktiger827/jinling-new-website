# Should You Use, Rework, or Return a Non-Conforming Stainless Lot?

The first decision is not whether to argue. It is whether to stop the lot.

If non-conforming stainless is cut, welded, polished, or mixed into stock before disposition, your clean return option may disappear. Hold first. Decide second.

Most cases then fall into four routes: accept, use with concession, rework, or reject/return.

## The Four Routes

| Route | When it fits | What must be recorded |
|---|---|---|
| Accept | Finding is not actually outside spec | Measurement basis and release note. |
| Use with concession | Outside spec but safe and fit for this use | Written concession, end-use limit, credit if any. |
| Rework | Defect can be corrected without harming the product | Rework method, cost owner, reinspection result. |
| Reject / return | Safety, code, grade, or functional requirement fails | NCR, evidence, return/replacement agreement. |

Do not use "concession" as a polite word for ignoring the problem. A concession is a controlled decision for one identified lot and one end use.

## Ask These Questions in Order

1. Is the material already processed?
2. Is safety, code compliance, food contact, pressure duty, or corrosion service affected?
3. Can engineering accept the deviation for this specific use?
4. Can the supplier approve the concession in writing?
5. Can rework restore compliance?
6. If return is no longer practical, what financial loss can be documented?

If safety or code is affected, stop looking for a cheap compromise. If the job is decorative and the defect is on a hidden face, concession may be perfectly reasonable.

## What Makes Return the Right Answer?

Return is usually right when:

- wrong grade was supplied
- heat identity is broken
- chemistry is confirmed out of spec for the application
- thickness or dimensions make the part unusable
- surface defect is on the visible or product-contact face
- code or customer requirement leaves no waiver route

Return is strongest before processing. After processing, the discussion often shifts to credit, rework cost, or shared loss.

## What a Concession Must Say

A useful concession states:

- NCR number
- PO and heat number
- exact deviation
- actual end use
- why the deviation is acceptable here
- price or cost adjustment
- names of the people approving it
- statement that future orders still follow the original spec

Without that last line, today's concession can accidentally become tomorrow's relaxed standard.

## Disposition Shortcut

Hold the lot, name the defect, decide the route, and write the decision. The calmest non-conformance files are not the ones with no problem. They are the ones where the problem never escaped into production without a written decision.
