# Get a Quote

`/get-quote` is now a focused pricing entry page. It opens with the quote basis first, then uses the same structured inquiry desk as `/contact`.

The quote path lives inside the contact desk because many inquiries are not actually quote-ready yet. Some need grade or finish review first. Some need a product-form route, document proof, shipment release check, or claim review.

For quote-ready requests, include:

- Product form.
- Grade.
- Finish.
- Size.
- Quantity.
- Destination port.
- Required delivery window.
- Tolerance, packing, inspection, or document requirements.

Start here: [Request pricing](/get-quote#contact-form).
